# 🌏 Sydney Travelling

A multi-page travel website designed to help users explore **Sydney, Australia** and discover some of its most popular attractions and places to visit.

## 🌐 Live Demo

🔗 **[Visit Sydney Travelling](https://g5-0148.github.io/SydneyTravelling/)**

## 📖 About the Project

Sydney Travelling is a front-end web development project focused on creating an engaging and user-friendly travel experience.

The website introduces visitors to Sydney, also known as the **Harbour City**, and provides information about places and attractions that make Sydney a popular travel destination.

The project was developed using core web technologies including **HTML, CSS, and JavaScript**.

## ✨ Features

- 🏙️ Sydney travel introduction
- 📍 Explore popular places and attractions
- 🌊 Information about Sydney's beaches and landmarks
- 🧭 Multi-page website navigation
- 📱 Responsive and user-friendly design
- 🎨 Custom styling with CSS
- ⚡ Interactive functionality using JavaScript
- 🔗 External links for additional information

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Interactivity and dynamic functionality
- **Git & GitHub** – Version control and project hosting
- **GitHub Pages** – Website deployment
